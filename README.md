# e-plantShopping

## Project Name
e-plantShopping 

## Description
e-plantShopping is an e-commerce web application for buying houseplants, built for
the company Paradise Nursery. It is built with React and Redux Toolkit. Users can
browse plants by category, add them to a shopping cart, change quantities, remove
items, and see the total cost.

## Features
- Landing page with the company name, background image, and a "Get Started" button
- About Us section describing the company
- Product listing with 18 houseplants in 3 categories (thumbnail, name, price)
- "Add to Cart" buttons that disable once a plant is added
- Navbar with Home, Plants, and Cart links, and a live cart item count
- Shopping cart page with per-plant totals, a grand total, quantity +/- buttons,
  delete buttons, a Checkout button ("Coming Soon"), and Continue Shopping

## Tech Stack
React, Redux Toolkit, React-Redux, Vite

## Run Locally
    git clone https://github.com/dhawal-cloud/e-plantShopping.git
    cd e-plantShopping
    npm install
    npm run dev
